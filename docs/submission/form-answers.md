2. Plugin Description* (exact answer):
   A Socratic tutoring guardrail for Hermes. A teacher arms a named student
   chat; from then on the hint level is database state, not a prompt
   instruction: observed student attempts are counted in SQLite and climb a
   4-level hint ladder (question, concept, structure, worked example on
   different data; the exact solution to the student's own problem is never
   the intended output). Measured reworded repeats of earlier work are
   rejected and logged; thorough rewording can still slip through. Model
   replies that leak solution-shaped content beyond the current level are
   screened and replaced with a level-appropriate fallback - a heuristic with
   measured, published misses. Teacher identity binds to configured runtime
   session ids and fails closed; the teacher gets the full learning trail
   with per-event actor attribution. Attempts are observed messages, not
   verified learning. The plugin adds no network calls, credentials or
   telemetry of its own.
